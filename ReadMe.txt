# MaunaLoa_FIs_Extrusives_2025
Supporting information for 2025 Wieser et al. paper (Fluid inclusion constraints on the geometry of the magmatic plumbing system beneath Mauna Loa: Part 1: Lavas and tephras)

Jupyter Notebooks
---------------------------
Calculating_pressures_from_densities.ipynb - This notebook shows how to calculate pressures using the H2O-CO2 EOS. It reads and applies the pickles relating XH2O to pressure, Fo content to temperature, Mg# to temperature


PartI_Tidy_Plots_For_Github.ipynb - Code to produce all non-MTEX figures. 


PyGMT_code_for_Figure2.ipynb - Code using PyGMT to plot the monitoring data

S_diffusion_final.ipynb - Code to run S diffusion model. 

PKL files
---------------------
XH2O_high, XH2O_low, XH2O_mean - define relationship between XH2O and pressure

TempFoModel - defines relationship between Fo content and temperature

TempOpxMgnoModel - defines relationship between Opx Mg# and temperature

Excel files
--------------------
Online Resource 1 - All data generated in this paper and literature data for comparison
Online Resource 2 - S degassing models

PDF files
------------------
Examples_of_EBSD_Classification - example EBSD maps and classification as deformed/undeformed

Fluid_inclusion_pictures-example FI pictures

GIFS
-----------------
diffusion_full_cross_Section - animated giffs showing evolution of S in the melt and fluid.
